# Start here

## Use the web app

Open the verified link listed in the latest GitHub Release or project About section. Describe your goal, choose a target, keep Economy selected for a concise prompt, and select **Craft prompt**. Review and edit the result before copying it to the target AI.

Memory stores only the preferences you enter. Use **Export backup** before clearing browser data, uninstalling a mobile app, or changing devices.

## Install Android

Only download an APK from this repository's official Releases page. Compare its SHA-256 checksum with the published checksum file. Android may ask you to allow installs from the specific browser or file manager; enable it only for that source and turn it off afterward. No APK is currently published.

## iPhone and iPad

Use the official TestFlight/App Store link when the project status marks it available. An IPA file is not a universal iPhone installer. No TestFlight build is currently published.

## Privacy reminder

The local builder does not call an AI model. If optional AI refinement is enabled, the app explains that the current brief will be sent to the configured provider after you tap the refinement button.
