# Contributing

Thank you for improving OSBlack Prompt Architect.

1. Discuss substantial product or data-model changes in an issue first.
2. Create a focused branch and preserve existing behavior and user data.
3. Run the checks in `AGENTS.md` and update documentation affected by the change.
4. Submit a pull request explaining behavior, validation, limitations, and screenshots for visual changes.

Never commit secrets, signing material, user data, generated private backups, or misleading release artifacts. Contributions require review by the repository owner. Participation is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
